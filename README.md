# 🌙 LunaFortuna

فروشگاه اینترنتی خرید واسطه‌ای از ترکیه برای ایران — «خیالت راحت، بقیه‌اش با ما».

سایت با **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma** ساخته شده و کاملاً داینامیک و دیتابیس‌محور است.

## امکانات

- **موجودی انبار تهران** (`/shop`): محصولات آمادهٔ ارسال با دسته‌بندی داخلی و قیمت تومانی.
- **کتگوری بر اساس برند** (`/brands`): ~۷۴ برند ترکیه با لینک مستقیم به سایت اصلی، تفکیک‌شده بر اساس جنسیت و زیردسته.
- **ثبت سفارش واسطه‌ای** (`/order`): فرم لینک + ماشین‌حساب لیر→تومان + شماره کارت + رسید، و کانال تلگرام.
- **قیمت‌گذاری خودکار**: نرخ لیر از کانال تلگرام خوانده می‌شود (Cron)، کارمزد پلکانی (۱۵/۱۲/۱۰٪).
- **حساب کاربری و داشبورد** (`/account`): ورود با ایمیل + کد فعال‌سازی، تاریخچهٔ سفارش، سطح وفاداری، کد معرف.
- **پنل ادمین** (`/admin`): مدیریت محصولات، برندها، بنرها، سفارش‌ها، تنظیمات (نرخ، کارمزد، کارت، دربارهٔ ما).

## راه‌اندازی محلی

```bash
npm install
cp .env.example .env      # مقادیر را پر کن
npx prisma db push        # ساخت دیتابیس (SQLite در توسعه)
npm run db:seed           # واردکردن برندها، دسته‌ها و دادهٔ نمونه
npm run dev               # http://localhost:3000
```

## متغیرهای محیطی

نمونه در `.env.example`. مهم‌ها:

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | SQLite در توسعه؛ Postgres در پروداکشن |
| `BOT_TOKEN` | توکن ربات تلگرام (اطلاع سفارش‌ها) |
| `ADMIN_CHAT_ID` | آیدی عددی ادمین تلگرام |
| `RATE_TG_CHANNEL` | کانال عمومی نرخ لیر (بدون @) |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | ورود پنل ادمین |
| `AUTH_SECRET` | سکرت نشست کاربران |
| `RESEND_API_KEY` | سرویس ایمیل برای کد فعال‌سازی (اختیاری) |

## استقرار روی Vercel

1. ریپو را به Vercel وصل کن.
2. در Vercel یک دیتابیس **Postgres** بساز (Storage → Postgres) تا `DATABASE_URL` خودکار ست شود.
3. در `prisma/schema.prisma` مقدار `provider` را به `postgresql` تغییر بده.
4. متغیرهای محیطی را در Vercel تنظیم کن.
5. پس از اولین دیپلوی: `prisma db push` و seed را اجرا کن.

Cron خواندن نرخ (`/api/cron/rate`) در `vercel.json` هر ۲ ساعت تنظیم شده است.

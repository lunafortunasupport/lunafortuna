# 🌙 LunaFortuna

فروشگاه اینترنتی خرید واسطه‌ای از ترکیه برای ایران — «خیالت راحت، بقیه‌اش با ما».

سایت با **Next.js 14 (App Router) + TypeScript + Tailwind CSS + Prisma** ساخته شده و کاملاً داینامیک و دیتابیس‌محور است.

## امکانات

- **موجودی انبار تهران** (`/shop`): محصولات آمادهٔ ارسال با دسته‌بندی داخلی و قیمت تومانی.
- **کتگوری بر اساس برند** (`/brands`): ~۷۴ برند ترکیه با لینک مستقیم به سایت اصلی، تفکیک‌شده بر اساس جنسیت و زیردسته.
- **ثبت سفارش واسطه‌ای** (`/order`): فرم لینک + ماشین‌حساب لیر→تومان + شماره کارت + رسید، و کانال تلگرام.
- **قیمت‌گذاری خودکار**: نرخ لیر از کانال تلگرام خوانده می‌شود (Cron)، کارمزد پلکانی (۱۵/۱۲/۱۰٪).
- **حساب کاربری و داشبورد** (`/account`): ورود با ایمیل + کد فعال‌سازی، تاریخچهٔ سفارش، سطح وفاداری، کد معرف.
- **پنل ادمین** (`/admin`): مدیریت محصولات، برندها، بنرها، سفارش‌ها، تنظیمات (نرخ، کارمزد، کارت، دربارهٔ ما).

## راه‌اندازی محلی

```bash
npm install
cp .env.example .env      # مقادیر را پر کن
npx prisma db push        # ساخت دیتابیس (SQLite در توسعه)
npm run db:seed           # واردکردن برندها، دسته‌ها و دادهٔ نمونه
npm run dev               # http://localhost:3000
```

## متغیرهای محیطی

نمونه در `.env.example`. مهم‌ها:

| متغیر | توضیح |
|---|---|
| `DATABASE_URL` | SQLite در توسعه؛ Postgres در پروداکشن |
| `BOT_TOKEN` | توکن ربات تلگرام (اطلاع سفارش‌ها) |
| `ADMIN_CHAT_ID` | آیدی عددی ادمین تلگرام |
| `RATE_TG_CHANNEL` | کانال عمومی نرخ لیر (بدون @) |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | ورود پنل ادمین |
| `AUTH_SECRET` | سکرت نشست کاربران |
| `RESEND_API_KEY` | سرویس ایمیل برای کد فعال‌سازی (اختیاری) |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | ورود با گوگل (اختیاری) |

### ورود با گوگل (اختیاری)

کاربر می‌تواند یا با «حساب گوگل» وارد شود یا با ایمیل + کد یک‌بارمصرف. برای فعال‌کردن
دکمهٔ گوگل:

1. در [Google Cloud Console](https://console.cloud.google.com/apis/credentials) یک
   **OAuth 2.0 Client ID** از نوع **Web application** بساز.
2. در **Authorized redirect URIs** این دو را اضافه کن:
   - `http://localhost:3000/api/auth/google/callback`
   - `https://www.lunafortuna.store/api/auth/google/callback`
3. `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET` را در `.env` (و در Vercel) قرار بده.

اگر این دو متغیر خالی باشند، ورود ایمیلی مثل قبل کار می‌کند و دکمهٔ گوگل پیام «فعال
نشده» می‌دهد.

## استقرار روی Vercel

1. ریپو را به Vercel وصل کن.
2. در Vercel یک دیتابیس **Postgres** بساز (Storage → Postgres) تا `DATABASE_URL` خودکار ست شود.
3. در `prisma/schema.prisma` مقدار `provider` را به `postgresql` تغییر بده.
4. متغیرهای محیطی را در Vercel تنظیم کن.
5. پس از اولین دیپلوی: `prisma db push` و seed را اجرا کن.

Cron خواندن نرخ (`/api/cron/rate`) در `vercel.json` روزانه تنظیم شده است (سقف پلن Hobby).

### استقرار خودکار (GitHub Actions)

چون اتصال مستقیم Git ↔ Vercel این پروژه کار نمی‌کند، استقرار خودکار از طریق
`.github/workflows/deploy.yml` انجام می‌شود: با هر push به `main` (یا اجرای دستی از تب
Actions) نسخهٔ production روی Vercel دیپلوی می‌شود.

تنها تنظیم لازم (یک‌بار): در GitHub → **Settings → Secrets and variables → Actions**
یک secret به نام `VERCEL_TOKEN` بساز و مقدارش را یک توکن از
Vercel (**Account Settings → Tokens → Create**) بگذار. شناسه‌های سازمان/پروژه از قبل در
فایل workflow هستند.

## حسابرسی لینک برندها

سایت‌های ترکیه ساختار URL دسته‌هایشان را مدام عوض می‌کنند. اسکریپت زیر همهٔ لینک‌های
عمیق برندها را می‌زند، لینک‌های مرده (۴۰۴/۴۱۰/ریدایرکت به صفحهٔ اصلی) را پیدا می‌کند و
صفحهٔ اصلیِ سالم هر برند را حل می‌کند:

```bash
node scripts/audit-brand-links.mjs --emit   # scripts/link-audit.json را می‌نویسد
npm run db:seed                              # لینک‌های مرده هرس، صفحهٔ اصلی اصلاح می‌شود
```

`prisma/seed.ts` هنگام seed این فایل را می‌خواند؛ لینک‌های مرده هرگز به مشتری نشان داده
نمی‌شوند و دکمهٔ «ورود به سایت» همیشه به یک صفحهٔ اصلیِ کارآمد می‌رود. این حسابرسی را
هرچند وقت یک‌بار دوباره اجرا کن تا داده تازه بماند.

### حسابرسی با مرورگر واقعی (دقیق‌تر)

بعضی سایت‌ها کد ۲۰۰ می‌دهند ولی با JavaScript کاربر را به صفحهٔ اصلی می‌برند — چیزی که
بررسی HTTP نمی‌بیند. اسکریپت زیر با مرورگر واقعی (Playwright) لینک‌ها را باز می‌کند و این
موارد را هم می‌گیرد. **از ترکیه اجرا کن** تا مثل تجربهٔ مشتری بخواند:

```bash
npx playwright install chromium   # یک‌بار
npm run audit:links:browser       # scripts/link-audit.json را به‌روز می‌کند
npm run db:seed                   # هرس نهایی
```

## حراج خودکار برندها

بخش «حراج‌های امروز» روی صفحهٔ اصلی، برای هر برندِ دارای حراجِ فعال یک بنر (لوگو + برچسب
+ دکمه) نشان می‌دهد که به صفحهٔ حراجِ همان برند لینک می‌شود.

- **دستی:** در `/admin/brands/[id]` می‌توانی `saleUrl`، برچسب، و کلید روشن/خاموشِ حراج هر
  برند را تنظیم کنی.
- **خودکار:** ورک‌فلوی `.github/workflows/check-sales.yml` روزانه صفحهٔ حراجِ هر برند را با
  Playwright چک می‌کند، درصد تخفیف را برای برچسب استخراج می‌کند، و بنرِ برندهایی که صفحهٔ
  حراجشان مرده را خاموش می‌کند (برندهای مبهم/بلاک‌شده دست‌نخورده می‌مانند تا تنظیم دستی از
  بین نرود). دستی هم می‌شود از تب Actions اجرایش کرد.

**تنظیم لازم (یک‌بار):** یک secret به نام `DATABASE_URL` (رشتهٔ اتصال Neon، همان که در
Vercel است) در GitHub → Settings → Secrets and variables → Actions بساز تا ربات بتواند در
دیتابیس بنویسد.
